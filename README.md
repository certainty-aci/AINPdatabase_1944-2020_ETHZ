# Ambient ice-nucleating particle (AINP) database 1944-2020 post processing notebook

## Overview
This Jupyter notebook includes functions for AINP database I/O, post-processing (mapping functions e.g. season, lat band, hemisphere, online/offline instrument) and visualization (e.g., global INP map).
